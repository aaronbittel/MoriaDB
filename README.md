# MoriaDB

MoriaDB is a database implementation written in Java, based on the tutorial series
[Trial of Code: Code a database in 45 Steps (Go)](https://trialofcode.org/database/).

The project follows the original Go implementation while adapting the architecture and
APIs to Java. It explores core database concepts including:

- schema-driven row encoding
- binary serialization
- key/value storage
- primary keys
- row decoding
- storage engine design

The goal of the project is educational: understanding how databases work internally by
implementing one from scratch.
